# AgentGuard — AI Agent Security & Governance Platform

AgentGuard sits between an LLM agent and its tools. Every prompt, model reply and proposed
tool call is checked against declarative policies and security detectors (prompt injection,
jailbreaks, PII / secret leakage) before anything executes, and every decision is written to a
tamper-evident, hash-chained audit log.

Full documentation is coming with v1.0.0.
